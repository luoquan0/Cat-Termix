# Cat-Termix Attribution and Modifications

Cat-Termix is a modified distribution based on the Termix project.

Upstream project:

- Termix
- https://github.com/Termix-SSH/Termix
- Baseline used for this repository: Termix 2.9.1 (`release-2.9.1-tag`)

Original copyright and license notices are preserved in `LICENSE`.

Cat-Termix-specific changes include product/repository branding, build and deployment configuration, exclusion of the upstream AI Assistant from bundled runtime plugins, and migration of the CloudSSH Agent device-authentication and remote-automation capabilities from https://github.com/luoquan0/Cat-Cloudssh.
