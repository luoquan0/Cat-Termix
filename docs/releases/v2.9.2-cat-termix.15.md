## 软件内更新与验收

先备份现有数据并安排 SSH 会话维护时间。管理员进入 **软件自动更新 → 立即检查 → 立即更新**，等待健康检查和容器重启。更新后在 **软件自动更新 → 代理地址** 输入 `http://192.168.1.2:7890`，或已有的 `https://` 代理地址，确认输入期间协议头完整保留，保存后刷新依然保留代理源地址。若代理包含凭据，服务端只会回显去掉密码的代理 origin；留空和保留密码仍遵循原有 `keepProxy` 规则。

本轮只发布仓库代码与 GHCR 镜像，**没有修改 2244 服务器正在运行的容器**；网页代理输入的修复在主应用更新后生效，独立更新器容器不会随主应用自动重建。保留原 Compose 配置、挂载和数据卷，不执行 `down -v`。升级前备份数据卷，SSH 会话在重启时会断开。
