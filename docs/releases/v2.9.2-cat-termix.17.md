# Cat-Termix 2.9.2-cat-termix.17 — Local Agent 安全 sudo 执行

**正式发布成功：2026-10-12 11:47 UTC。** 完整 AI、Agent、SSH、核心和更新器回滚测试、原生 AMD64/ARM64 容器启动及 GHCR 晋升均通过。当前 2244 服务器未被远程修改。

## 功能

在本地 Agent 的结构化 SSH 任务中增加 `sudo: true` 选项；新版 `cloudssh.mjs` 支持：

```bash
node <cloudssh.mjs 的路径> jobs run --server <主机ID> --command "id -u" --sudo
```

运行效果：**只将这一条非交互命令以 root 身份执行**，不是把 SSH 用户永久改成 root，也不会创建常驻 root 终端。普通 `jobs run` 行为保持不变。SSH 登录账号必须能使用 sudo，且主机所有者已在 Cat-Termix 保存正确的 sudo 密码。

## 三道独立的权限边界

1. 本地 Agent 设备必须被主机所有者在「本地 Agent → 编辑权限」中额外授予 `jobs:execute` 和 **`sudo:execute`**。后者是新增高风险设备权限，旧设备、旧授权及新配对设备默认均不含它。
2. Local Agent 插件的清单新增 **`ssh:sudo`**（Critical）核心能力，必须在平台插件权限中心**单独批准**后才能调用。内置插件原本会自动获得清单新增能力，但本版明确把 `ssh:sudo` 排除在自动授予之外，阻止升级时悄悄获得 root 执行能力。
3. 服务端再次校验设备签名、授权主机范围、对应用户的 SSH 连接权限及宿主机所有者身份。分享给别人的 SSH 主机不能使用原主人的 sudo 密码；普通主机管理、SFTP 和未获 sudo 权限的任务不受影响。

## 密码安全与审计

- sudo 密码仅在 Cat-Termix 核心 SSH 后端解密，通过独立 SSH channel 的 stdin 发送给远程 sudo；**不会返回到 Agent API、插件对象、CLI 输出、任务存储或审计记录中**，也不会拼接进远程 shell 命令。
- 即使目标机 sudo 缓存有效或配置 NOPASSWD，实际执行 root 命令之前也会将命令的标准输入重定向到 `/dev/null`，防止未被 sudo 消费的密码沿 stdin 泄露给命令。
- 任务支持原有的超时、取消、设备撤权关闭与输出长度限制；提权操作有独立审计事件，但不记录 sudo 密码或执行的完整命令。
- `sudo: true` 必须是布尔值；无设备授权时在创建幂等记录之前拒绝，以免产生错误 409。两项设备权限缺一不可。
- 注意：获得了 root 命令执行权限的设备理论上可读取和修改服务器上的任意信息；只有完全可信的 Agent 客户端应获此授权。此功能不能用于不受信任的 AI 工作流。

## 部署与启用

1. 备份数据卷并安排 SSH 会话维护时间，进入 Cat-Termix **管理员设置 → 软件自动更新 → 立即检查 → 立即更新**，从 `ai-dev` 获取正式 v17。
2. **管理员插件权限**：对内置 **Local Agent** 的 `ssh:sudo` Critical 能力点击批准。此项升级后不会自动授予。
3. **本地 Agent → 已配对设备 → 修改授权**：仅为完全可信的设备勾选 `jobs:execute`、`sudo:execute`，限制可访问主机范围并保存；不用重新配对。
4. 确认 SSH 主机由当前用户拥有，SSH 账号支持 sudo，且该主机 SSH 设置已保存正确的 sudo 密码。
5. 把本地计算机使用的 `skills/cloudssh-agent/scripts/cloudssh.mjs` 更新到本次仓库版本，然后先执行无害命令 `node <脚本路径> jobs run --server <主机ID> --command "id -u" --sudo`；输出 `0` 代表以 root 执行成功。真正进行修改前应明确命令和影响范围。

**注意：** 本功能提供的是单次 root 任务而不是永久 root 终端；给 Agent 授予此能力意味着它可以对授权主机执行任意高权限命令，只向可信 Agent 开放。实际用户服务器的 sudo 端到端操作仍需要上述人工测试；CI 只验证核心 SSH 逻辑和 API、权限、容器运行，并未连接用户的生产 SSH 主机。

**不直接修改用户现有 2244 服务器**；主应用升级后管理员仍需批准插件的新增 Critical 能力、给指定设备编辑 sudo 权限，同时本地计算机上的 CloudSSH Agent Skill/CLI 脚本如为旧版本需要更新到仓库新版以获得 `--sudo` 参数。部署前备份数据，SSH/SFTP 重启会断线。原版 `main` 与 Termix 上游不动。
