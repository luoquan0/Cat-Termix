# Cat-Termix 2.9.2 · AI + Local Agent

这是 Cat-Termix 项目自己的正式用户验收版本，**不是原版 Termix 的官方更新，也不是旧 Cat-Cloudssh 的逐项复制**。

## 更新内容

- 保留新版 AI 对话、SSH 网页终端与自动更新功能。
- 新增独立 Local Agent 插件：Ed25519 设备签名、一次性配对码、网页审批、主机范围授权、scopes 与撤销。
- 新增 SSH Jobs、交互式终端会话/tmux 和 SFTP 操作。
- 支持管理员设置可信局域网 HTTP IPv4 CIDR，默认优先 HTTPS；明文客户端必须显式 `--allow-http`。
- 旧版团队项目与设备配对信息不自动迁移，旧 CloudSSH 只作使用效果参考。

## 升级与回退

AMD64 部署：系统管理员设置 → 软件自动更新 →「立即检查」→ 确认「立即更新」。未开启自动安装的实例不会仅因发现新版本自动重启。升级会中断 SSH 和 AI 会话，更新器先做冷备份，并提供健康失败回滚。仍建议先自行备份重要数据。

Preview 8 保留镜像 `ghcr.io/luoquan0/cat-termix:2.9.2-ai-preview.8`（源码 `de43f279300877439c2a65e0e914816d3938c542`），必要时可据此安排回退。回退前检查数据库兼容性与备份，不要直接删除数据卷。
