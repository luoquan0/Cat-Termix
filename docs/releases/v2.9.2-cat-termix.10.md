## ARM64 部署

确认宿主机是 `aarch64` 或 `arm64`：

```bash
uname -m
docker pull --platform linux/arm64 ghcr.io/luoquan0/cat-termix:ai-dev
```

如果使用项目提供的 Docker Compose 文件，在安装目录执行（不要更换现有数据卷名称）：

```bash
export CAT_TERMIX_IMAGE=ghcr.io/luoquan0/cat-termix:ai-dev
docker compose -f docker-compose.ai-test.yml -f docker-compose.ai-updates.yml pull
docker compose -f docker-compose.ai-test.yml -f docker-compose.ai-updates.yml up -d
```

已经启用了网页自动更新器的标准 Compose 部署也可以在「管理员设置 → 软件自动更新」点击「立即检查」，待确认后手动更新。**如果当前正在运行的同源码版本是 AMD64，则切换 ARM64 平台不一定通过版本号差异检测触发自动更新；请用显式 `docker compose pull/up -d` 安装。**

## 安全与已知限制

- 替换容器会断开 SSH 和正在执行的 AI 请求；保留原数据卷、原环境变量和原端口，先备份再维护更新。
- 真实用户 SSH/SFTP 主机连接及复杂 CIDR 网络策略仍需在测试服务器上人工验收，自动化容器测试不代表生产部署全部完成。
- GitHub Actions 创建 GitHub Releases 条目和 Git 标签被仓库授权拦截（HTTP 403）；以上是已验证的 **GHCR Docker 发行镜像**，未宣称 GitHub Releases 页面已有同名条目。
