# Local Agent sidebar regression hotfix (Preview 10)

Previous release `v2.9.2-cat-termix.9` (AMD64) registered the Local Agent rail item and a standalone tab, but omitted the sidebar panel registration. Clicking the robot icon displayed the core "Local Agent unavailable; this feature has been removed" placeholder even though the plugin was installed.

**Fix:** register the Local Agent sidebar panel with the existing plugin host, and keep its standalone tab and administrator HTTP settings extension intact. Adds a frontend test that mounts the real panel and checks registration/deactivation.

- Platform: Linux AMD64 (ARM64 not yet validated).
- Test tag (after CI): `ghcr.io/luoquan0/cat-termix:2.9.2-ai-preview.10`
- Rolling release promotion to `ai-dev`: only after full CI and container smoke succeed.
- Preserves original Termix `main`, existing AI chat, SSH terminal and updater code.
- Old fixed rollback tags retained: `2.9.2-cat-termix.9`, `2.9.2-ai-preview.8`.
- Real-user SSH/SFTP sessions and network policy still need user acceptance tests.
