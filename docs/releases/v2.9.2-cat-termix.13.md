## 修复内容

1. **聊天设置里的多个启用模型：** 在渠道下同时勾选多个模型，支持搜索、全选、清空、自定义模型 ID、保存。保存后外侧聊天输入框的模型切换菜单即时更新；每条消息使用用户当时选中的一个模型，而不是多模型同时生成回答。
2. **模型持久化与安全回退：** 复用现有用户级渠道模型启用列表，不增加数据库迁移。保留已选择模型；从启用列表中移除当前模型时回退到仍允许的模型；全部禁用时不会允许用已取消授权的模型发送。
3. **聊天设置弹窗自适应：** 桌面最大宽度 900px，窄屏自动调整单列，限制横向溢出；长模型 ID 自动换行；上下内容仍可纵向滚动。重点解决弹窗右侧需要拖动才能看到的问题。
4. **保持 v12 修复：** Agent 代理安全、设备授权编辑与以后新增 SSH 主机、撤销后删除设备记录、渠道思考程度选择等均未被此次修复覆盖。

## 从软件页面更新

建议先备份数据卷并结束正在进行的 SSH/SFTP 操作；更新时应用容器需要重启，已有会话将断开。使用现有 Cat-Termix 独立更新器和 `ai-dev` 渠道：

1. 打开 **管理员设置 → 软件自动更新**。
2. 点击 **立即检查**；应检测到基于源码 `3785e15a` 的 v13 新镜像。
3. 确认维护窗口和备份，再点击 **立即更新**，等待重启和健康检查。若配置了自动安装，请遵循现有更新调度。

本轮**已发布 GHCR 镜像，但未远程修改用户正在运行的服务器**；真实服务器的弹窗尺寸、模型 API 连通性及所有 SSH/SFTP 终端业务仍须在实际部署中人工验收。
