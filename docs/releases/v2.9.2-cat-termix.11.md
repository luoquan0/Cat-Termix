## AI 助手体验改进

聊天框下方新增类似 ChatGPT 的圆角输入区域，模型选择直接显示当前渠道名称。模型菜单按当前账号已启用的多个渠道分组，同名模型不会混用其他渠道的 API Key。原 OpenAI、OpenAI 兼容、Anthropic、Gemini、Ollama 渠道均保留；已有 API Key 无需重新录入。自定义模型 ID 仍可在聊天设置中配置。

新增思考程度选择：自动、关闭、低、中、高、极高；渠道设置可保存该渠道的默认思考程度。请求参数按服务商适配，部分服务商不支持全部档位或会降级映射；`自动` 避免对原有网关强制注入参数。

模型、渠道、思考程度和逐次审批/免审批状态现在作为**当前用户的持久偏好**保存在服务端。新建会话与重新打开聊天面板时继承这些偏好，而打开旧会话保留其已有模型信息。免审批开启后会持续保持，直到用户主动关闭；并不绕过 RBAC、主机访问限制或审计。

## 数据与安全

新增了 SQLite、PostgreSQL、MySQL 的用户偏好表迁移与两种数据库的已审核升级快照。AI 通道 API Key 继续存储在原受保护的 secrets 中，不进入偏好 JSON。完整回归包含 250 项 AI、12 项 Agent、425 项 SSH 以及核心应用和 Docker 更新回滚测试。AMD64/ARM64 镜像在原生运行器上构建并实际启动，检测了网页登录页面、后端健康、内置 AI/Agent 与 Ed25519 协议。

**部署前请备份数据卷。** 更新重启会断开已有 SSH 和未完成的 AI 请求。真实业务 SSH/SFTP 目标与第三方模型网关的不同思考档位仍需在用户自己的服务环境中验收。

GitHub Actions 没有创建 GitHub Releases 条目的仓库权限，因此以验证成功的 GHCR 镜像为发布物，不将 Release 页面条目与 Docker 发布混淆。
